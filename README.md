# BiteBack 🍽️

## Smart Surplus Food Management System

BiteBack is a web-based platform designed to reduce food wastage by connecting restaurants, hotels, canteens, bakeries, and event organizers with users who can purchase or collect surplus food at affordable prices.

## 🚀 Features

* User Registration and Login
* Provider Registration and Login
* Add Surplus Food Listings
* Upload Food Images
* Browse Available Food Items
* Order / Book Food
* Admin Dashboard
* Accept / Reject Requests
* Database Management

## ⚙️ Installation Steps

1. Install **XAMPP**.
2. Copy project folder to `htdocs`.
3. Start **Apache** and **MySQL**.
4. Import database file into **phpMyAdmin**.
5. Open browser and run:

```text
http://localhost/biteback/
```
